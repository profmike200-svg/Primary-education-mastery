# Clements, D. H., & Sarama, J. (2014). Learning and teaching early math: The learning trajectories approach (2nd ed.). Routledge.

## Resumen (con palabras propias)
Describe trayectorias de aprendizaje para las matemáticas tempranas (conteo, subitización, suma y resta, geometría…).

## Ideas clave
- Cada trayectoria combina un objetivo, una progresión de niveles de pensamiento y tareas para cada nivel.
- Base del programa *Building Blocks*, evaluado con resultados positivos.
