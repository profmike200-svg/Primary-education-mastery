# Aprendizaje para el dominio

## En una frase
Dividir el contenido en unidades y no avanzar hasta que todo el alumnado alcance un nivel alto de dominio (p. ej. un 80 %), con evaluación formativa y apoyo correctivo.

## Fundamento teórico
Propuesto por [[Bloom]] (1968): con el tiempo y la ayuda adecuados, la mayoría del alumnado puede alcanzar el dominio.

## Cómo se aplica (paso a paso)
1. Objetivos claros por unidad.
2. Enseñanza inicial ([[Instruccion_Explicita]]).
3. Evaluación formativa breve ([[Evaluacion_Formativa]]).
4. Actividades correctivas para quien no domina; ampliación para quien sí.
5. Nueva evaluación antes de avanzar.

## Evidencia
**Nivel:** B · Impacto positivo moderado según el [[EEF_Toolkit]], mayor con alumnado con dificultades. Exige organizar bien el tiempo para quien termina antes.

## Errores frecuentes al aplicarla
- No ofrecer ampliación real a quien ya domina (aburrimiento).
- Avanzar por calendario aunque la mitad del grupo no domine la base.
