# Glosario entre sistemas educativos

Equivalencias **aproximadas**. Las figuras y los procedimientos no son idénticos: comprueba siempre la normativa local (estatal, autonómica o del distrito escolar).

## Estructura
| España | EE. UU. | Reino Unido (Inglaterra) | Notas |
|---|---|---|---|
| Educación Primaria (6-12) | Elementary school (K-5) + 6th grade | Primary (KS1-KS2) | En EE. UU., 6th grade suele pertenecer a la middle school |
| Educación Infantil 2º ciclo | Pre-K / Kindergarten | EYFS / Reception | Kindergarten (5-6 años) suele ser obligatorio en EE. UU. |
| Tutor/a | Homeroom teacher | Class teacher | |
| Centro público / concertado / privado | Public / charter / private school | State / academy / independent | Concertado ≈ sin equivalente exacto |

## Currículo y evaluación
| España | EE. UU. | Reino Unido | Notas |
|---|---|---|---|
| LOMLOE, currículo estatal + autonómico | Common Core (ELA, Math), NGSS (ciencias), estándares estatales | National Curriculum | En EE. UU. cada estado decide |
| Competencias clave / específicas | Standards / competencies | Programmes of study | |
| Saberes básicos | Content standards | Subject content | |
| Situación de aprendizaje | Unit / project-based unit | Scheme of work / unit | |
| Programación didáctica | Curriculum map / unit plan | Medium-term plan | |
| Evaluación criterial | Standards-based grading | Assessment against age-related expectations | |
| Pruebas de diagnóstico | State standardized tests | SATs (KS2) | |
